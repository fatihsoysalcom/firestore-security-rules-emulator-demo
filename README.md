# Firestore security rules emulator demo

This example demonstrates how to connect to the Firebase Firestore emulator and test security rules. It simulates writing and reading data to collections with different access permissions, showing how the emulator enforces rules.

## Language

`javascript`

## How to Run

1. Ensure you have the Firebase Emulator Suite installed and running (firestore: 8080, auth: 9099). 2. Replace placeholder values in `firebaseConfig` with your project details. 3. Open this HTML file in your browser and click 'Initialize Emulator'.
